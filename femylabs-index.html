About

A research-driven security company
built for compliance-critical environments

Femylabs LLC is a technology company specializing in privacy-preserving security infrastructure for regulated industries. We build software systems that enforce compliance requirements at the architecture level — not through policy overlays applied after the fact, but through cryptographic and systems engineering decisions made before the first line of production code is written.

Our work spans three verticals: cloud infrastructure security for AWS environments, privacy-minimizing location verification for healthcare and logistics compliance, and AI-assisted security operations for organizations running generative AI at enterprise scale. Across all three, the design principle is the same — the system should make the secure choice the path of least resistance.

Femylabs holds a filed USPTO provisional patent covering the Zero-Knowledge Route Promise (ZKRP) cryptographic protocol, a production deployment in a Medicaid-funded care management platform, and an active pipeline of commercial licensing conversations with EVV platform operators, insurance telematics companies, and fleet management providers.

Patent — Filed

Zero-Knowledge Route Promise (ZKRP)

A privacy-minimizing cryptographic commitment scheme that allows a mobile device to prove physical presence at a location — or route completion — without transmitting or storing raw GPS coordinates. The device evaluates a geofence condition locally, commits to the boolean result using HMAC-SHA256, and transmits only the commitment, geofence identifier, timestamp, and protocol version. The verification server confirms authenticity without ever receiving latitude or longitude values.

Deployed in production in Veraphos for Electronic Visit Verification compliance under the 21st Century Cures Act. Commercial licensing conversations active with EVV platform operators, insurance telematics companies, and fleet management providers.
